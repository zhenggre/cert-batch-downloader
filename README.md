# 证书批量下载器

从「表单大师 / biaodan100.com」公开证书查询页，**批量查询并下载证书 PDF**，按学校自动分文件夹归档、文件名用学生姓名。自带本地网页界面，勾选名单即可跑，支持「先随机试跑」防手滑。

> ⚠️ **本仓库只含工具源码。**
> 学生/学校数据、作者私有站点配置、以及打包好的二进制（exe / `_internal` / `runtime`）**一律不纳入版本库**，见 `.gitignore`。
> 想自己用，请按下面「快速开始」从 `*.example.*` 模板生成你自己的配置。

---

## 它能干什么

- 给定一份「姓名 + 证件号」名单（Excel），按比赛查询页批量查证谁获奖、证书文件在哪
- 自动把证书 PDF 下载下来，按**学校**分目录、按**姓名**命名
- 学校名自动归并（同校不同写法 → 一个文件夹），也可手工修正表兜底
- 本地网页界面：上传名单、勾选、点开始；跑的过程中显示进度，跑完给汇总清单（xlsx）+ 运行日志
- **试跑模式**：勾上「先随机试跑」只查几个人，界面/日志/清单都会明确标「🧪 试跑」，避免把"只查了 8 个"误当成"跑完了"
- 合规限速：每条之间可设间隔秒数，调太低会被网站当机器人封 IP，程序会自动拦住

## 快速开始（自己部署）

1. **准备运行环境**：本工具用一个随附的 Python（`程序/runtime/`，不进库）。首次需联网装依赖，见 `程序/_runtime_dl/get-pip.py`。
2. **生成配置**：把 `程序/config.example.json` 复制为 `程序/config.json`，按里面的 `_说明` 把你的比赛查询页填进去（也可在界面点「＋ 新比赛」自动识别）。
3. **学校名修正（可选）**：把 `程序/学校名映射.example.csv` 复制为 `程序/学校名映射.csv`，按需要手工指定归并。
4. **跑界面**：启动 `web_app.py`，浏览器打开提示的地址，上传名单 → 勾选 → 开始。

> 本仓库**不含打包好的 exe**（即 `① 双击就能用（直接用不用装任何东西）` 交付包，内含 `_internal/` 运行环境）。想要双击即用，在 `开发维护/` 下执行 `build.py` 自行打包。

## 安装与卸载的安全设计

这一节不是装饰。2026-09-22 出过一次真实事故：早期版本的卸载脚本里写着

```bat
rmdir /s /q "%DIR%"
```

`%DIR%` 是用户在文件夹对话框里**任选**的目录。有人把安装目录选成了「桌面」，
卸载时整个桌面被递归**永久删除** —— `rmdir` 不走回收站，找不回来。

现在有三条硬规则，改安装/卸载代码时不得破坏：

1. **不存在「对用户目录的递归删除」这条路。**
   卸载只删 `install_manifest.json` 里登记的、且 SHA256 对得上的文件；
   目录只在「内容与清单完全一致」或「已经是空目录」时才处理。
2. **一切删除先进回收站。** 系统被设成「删除时不进回收站」时整体放弃删除 ——
   删不掉比删错好。
3. **安装目录必须过路径守卫。** 桌面/文档/下载/主目录/OneDrive/盘根/Windows/
   Program Files 根一律拒绝；桌面或文档里的**专属子目录**允许，但要用户确认。
   判定用 Known Folder API 取系统认定的真实路径，并且先解析 junction ——
   靠猜目录名或纯字符串比对会被重定向和符号链接绕过。

回归测试在 `③ 安装包/构建脚本/test_installer_safety.py`，在系统临时目录的沙盒里
跑完整装卸流程，覆盖桌面/文档/下载/盘根/非空目录/清单篡改/路径穿越等用例。

## 构建（出交付包）

在 `开发维护/` 下执行 `build.py`（需要 PyInstaller 和本机 runtime）：

```bash
cd 开发维护
python build.py
```

产物在 `① 双击就能用（直接用不用装任何东西）/证书下载器/`，顶层正好 6 项：`证书下载器.exe` / `_internal/` / `使用说明.txt` / `保存位置说明.txt` / `config.json` / `学校名映射.csv`。

## 合规提醒

- 查询页是主办方公开的，**只查、不暴力刷**；速度上限由「每条间隔秒数」控制，别调太低。
- 被网站风控挡住时程序会自动停，**不要换 IP 硬绕**——那是把"效率"凌驾在对方 `robots.txt` / 限流意愿之上。
- 本工具下载的是**证书 PDF**，属于学生个人材料，落在你自己机器上，别外传、别进公开链接。
